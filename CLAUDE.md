# Kishkentai — заметки для Claude Code

Платформа раннего развития речи для детей **1–6 лет**, **три языка**: английский, казахский, русский.
Владелец — Аяжан Сагындыкова (sagindikovaaya@gmail.com). Общается по-русски, иногда по-казахски.
Сайт: https://sagindikovaaya-hue.github.io/kishkentai/ (GitHub Pages, ветка `main`, корень репозитория).
Короткий адрес https://sagindikovaaya-hue.github.io/ — отдельный репозиторий `sagindikovaaya-hue.github.io`
с одной страницей-переадресацией сюда (нужна для ссылок входа из писем Supabase).

## Как собрать и опубликовать

```
python3 src/build.py          # → index.html (сайт) и build/preview.html (для артефакта Claude)
git add -A && git commit -m "…" && git push
```
Всё собирается в **один файл** `index.html` (~5 МБ: картинки внутри как base64).
После изменений **поднимите версию кэша** в `sw.js` (`kishkentai-vN` → `vN+1`), иначе установленное
на телефоне приложение покажет старую копию.

## Устройство

| Файл | Что внутри |
|---|---|
| `src/content.js` | Весь контент: `THEMES` (слова на en/kk/ru + транскрипция для англ.), `SOUNDS` (звуки животных/транспорта), `ITEM_PHRASE` (фраза на каждой карточке), `LIFE` (блоки фраз для родителей), `PRAISE`, `SAY` (построение вопросов на каждом языке), `T` (интерфейс kk/ru), `LEVELS`, `PROGRAM`, `P` (тексты плана дня) |
| `src/app.js` | Логика: профили детей, главный экран «Сегодня играем» (`home`), программа по дням (`dayPlan`), игры (`listen`, `peek`, `learn`, `find`, `whoSays`, `memory`), прогресс, раздел «Родителям» с печатью |
| `src/account.js` | Вход родителя по email (Supabase), синхронизация профилей детей |
| `src/base.css`, `src/extra.css` | Стили. Токены цветов в `:root` в base.css |
| `src/painted.json` | Все картинки (600×800 JPEG, base64) по ключу. Цвета — `c-red` и т.д., текстуры цифр — `d-#HEX` |
| `audio/` | Записанная озвучка: `audio/index.json` (`"en|текст"` → файл) и `audio/en/*.mp3`. Подгружается при нажатии, нет записи — говорит голос телефона |
| `tools/` | `voice_texts.js <тема|games>` — все фразы темы (или новых игр), как их произносит приложение; `make_audio.py <тема> [--lang en] [--limit N] [--dry]` — запись через ElevenLabs API |
| `src/clips.json` | Старый способ (вшито в страницу), не используется |
| `art/` | Оригиналы картинок (PNG/JPG) |
| `supabase/schema.sql` | Таблицы `families`, `subscriptions` + RLS |
| `manifest.webmanifest`, `sw.js`, `icon-*.png` | Установка на телефон (PWA) и офлайн |

**Уровни по возрасту** (`LEVELS` в content.js) и игры (`src/games.js`, запуск через `GAME_RUN[id]()`):
- **Сәби** (1 год, без ошибок и без звёзд в шапке): Слушай, Прятки, Тук-тук (дверка → животное и его звук),
  Пузырьки (лопать пузыри с картинками), Спокойной ночи (укладываем игрушки, экран темнеет).
- **Балапан** (2 года): Найди, Кто так говорит?, Найди пару, Чья тень? (силуэт делается из акварели в canvas),
  Покорми (`FEED`: кот→молоко…), Одень, Какого цвета? (`COLOR_OF`).
- **Құлыншақ** (3 года): + Что лишнее?, Посчитай (`COUNTABLE`, до 5), Что пропало?
- **Батыр** (4–6 лет): Первая буква, Собери слово (слова до 5 букв), Посчитай (до 10), Картинка и слово,
  Повтори (родитель жмёт «Сказал ✓» → слово в прогрессе отмечается как «говорит»), + игры 3 лет.
Новая игра: функция в `games.js`, строка в `GAME_RUN`, имя в `GT` (kk/ru), картинка в `GAME_ART`, обернуть в `nav()`
в конце `app.js`, добавить id в `LEVELS[].games`. Фразы игр на трёх языках — объект `G` в content.js.
Таймеры перехода к следующему раунду — только через `later(fn, ms)`: он не сработает, если человек ушёл с экрана.
**Программа** (`dayPlan`): **каждый день новая тема** по списку `PROGRAM` (владелец просила, чтобы неделя не была
целиком про животных). Когда тема приходит снова, задание следующее: слова → новые слова → игра → фразы в жизни →
повторение. День d: тема `seq[d % seq.length]`, задание `DAY_KIND[floor(d / seq.length) % 5]`.
**Навигация:** каждый экран — запись в истории браузера (`nav()` в конце `app.js`), поэтому работают кнопка
«Назад» телефона, свайп на iPhone и стрелки браузера. Внизу постоянная панель «← Назад · ⌂ Главная · Вперёд →»
(`#nBack/#nHome/#nFwd`). Листание карточек и следующий раунд игры историю не засоряют (заменяют запись).
Новый экран = обычная функция, обёрнутая в `nav()` там же.
**Профили:** у каждого ребёнка кнопки «Изменить» и ✕ (удаление в два нажатия). Пока профиля нет, в шапке «+ Бала қосу».

## Как добавить тему

1. Картинки: обрезать до 3:4, 600×800 JPEG, положить в `art/` и добавить в `src/painted.json`
   (`{"ключ": "data:image/jpeg;base64,…"}`). Картинки владелец присылает фотографиями из Gemini —
   у многих есть рамка/подложка вокруг листа, её надо обрезать.
2. `content.js`: тема в `THEMES` (`[ключ, en, kk, ru, транскрипция, мн.ч.англ?]`), фраза каждой карточки
   в `ITEM_PHRASE`, блок из 7 фраз в `LIFE` (title/intro на kk и ru, у каждой фразы `when`),
   тема во все `LEVELS[].themes` и во все списки `PROGRAM`.
3. Собрать, проверить в браузере, запушить, поднять версию `sw.js`. Playwright на этой машине нет:
   проверять через `python3 -m http.server` и Chrome-расширение. Service worker держит старую копию —
   перед проверкой сбросить его (`navigator.serviceWorker.getRegistrations()` → `unregister()`, `caches.delete`).
4. Озвучка темы: `python3 tools/make_audio.py <тема> --lang en` (см. «Озвучка» ниже), закоммитить `audio/`.

  После скачивания **проверять, что в Downloads появился новый файл** (иначе в базу попадёт предыдущая картинка).
- **Озвучка (ElevenLabs API):** ключ и ID голоса лежат в `~/.config/kishkentai/elevenlabs.env` (вне репозитория,
